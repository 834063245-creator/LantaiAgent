## 3. 核心概念（来自总设计）

- **工作区画布状态文件**：`{ 摊开集合: [{sessionId, anchorX, anchorY, width}], activeSessionId? }`，随工作区走。与公共物同一归属，本阶段先建布局，公共物并入（拍板 11：「布局 + 公共物合一为工作区画布状态文件」）。
- **公共物 = 不绑死会话的一切**（2026-08-26 用户拍板）：钉住块、纸条、布局位置、将来的批注，只要不跟会话绑死，都属于公共物。当前 pinned/strips 是会话级，需升级语义：从"会话的附属"变"纸的居民"。宿主模型落地的完整定义。
- **写写画画（手写笔迹）= 暂缓**：缺口挂起，公共物新能力待后拾。

## 4. 子任务分解（拓扑序，每个独立可测）

**4.1 画布布局持久化（欠账补，优先级最高）**
- 工作区画布状态文件：摊开集合 + 流区位置，随工作区落盘/恢复
- 重启进画布恢复摊开（推翻 Q-B 在画布语义下的适用）；位置恢复到各流区
- 与现有 region（随卷）的收敛：region 从卷快照迁到工作区画布状态文件（或双读过渡后拆除卷级）
- 可测：单测（保存/恢复形状）+ 实机（摆好两会话位置 → 重启 → 原样恢复）

**4.2 公共物工作区级升级（不绑死会话即公共物）**
- pinned/strips/布局位置从会话级 → 工作区级（属工作区画布状态文件）
- 语义：不绑死会话的一切都是公共物；会话退场（删除）不连坐；钉到拔为止
- 宿主模型落地：公共物是独立宿主（完整定义：不绑会话即公共物）
- 可测：单测（会话删除后公共物保留）+ 实机（钉一个 plan → 删会话 → plan 还在纸上）

**4.3 写写画画（手写笔迹）= 暂缓**
- 缺口挂起，不做；不阻塞本阶段其他项

**4.4 工作区切换收口 + 零目录退役**
- 点工作区卡进画布、关卷回首页总览（已基本具备，补细节）
- 首页/侧边栏会话口径一致（四阶段 P4-1：首页显示 3 卷、侧边栏却"暂无会话"）
- **退役自动创建零目录会话动作**（cold-start 占位 Agent 不再自动造无目录会话；无目录=首页选/建工作区）
- **存量零目录卷彻底退役**：绑目录或归档（零目录概念整体消失，无目录不能进画布）
- 可测：实机（切换工作区 → 画布换成对应工作区布局；冷启动无目录不再自动造零目录会话）

**4.5 长流区阅读迭代（实机反馈）**
- 依赖四阶段目次带返工（P1-2 落点位置）完成后，实机体验反馈
- 不预设计，喂反馈调

**4.6 旧路径拆除（原则四）**
- region 卷级快照的残留清理（若迁到工作区级）
- 会话级 pinned 假设（随卷存）清理
- 可测：门禁全绿 + 无旧路径残留核查

## 5. 技术方案要点（Agent 执行用，简略）

- **工作区画布状态文件位置**：`.lantai/` 下工作区级（对齐 session-unify 两级结构：会话消息全局位、画布布局工作区位）。存 `StoredWorkspaceCanvas` 形状。
- **摊开集合**：`[{ sessionId, anchorX, anchorY, width }]` + activeSessionId。加载时按 sessionId 恢复流区；无记录 = 空画布。
- **公共物升格**：pinned/strips 从 `sessions[sid]` 提到工作区级容器；渲染读工作区级。块 source（活引用）保持。
- **写写画画**：若走 Canvas ink——新 kind（如 `draw`）+ 块渲染器注册 + 创建手势（创作坞/纸面工具栏？）+ 持久化进工作区画布状态文件。

## 6. 插件化约束（原则二/三）

- 写写画画 = 公共物形态 = 插件/贡献行（块渲染器通道 + 新 kind）
- 画布布局持久化 = 内核数据层（工作区画布状态是平台状态，属核心，但存储/恢复是数据面）
- 公共物升格 = 内核数据语义变化（宿主模型落地）
- 验收含「写写画画以贡献行注册」证据

## 7. 验收清单（阶段完工 = 功能 + 拆旧 + 门禁全绿）

- [ ] 布局持久化：重启恢复摊开 + 位置

- [ ] 写写画画：能画/写/批注，重启还在
- [ ] 工作区切换：口径一致（首页/侧边栏对得上）
