## P0-1 全放确认条 + 关窗 → 进程崩溃

- **现象**：权限档切到「全放」弹出确认条时，点 ✕ 关窗 → 进程直接 abort。
- **证据**：`wry-0.55.1 webview2/mod.rs:1256 null pointer dereference`，exit code `0xc0000409`，整个 dev 会话陪葬。
- **复现路径**：创作坞设置行点权限 → 全放确认条出现（`pendingYolo=true`）→ 点 ✕ 关窗。
- **期望**：关窗正常退出；任何状态下关窗都不得崩溃。
- **疑似落点**：`app/panels/ComposerDock.tsx` 的 yolo 确认条（`pp-yolo-confirm`）与窗口销毁时序的竞态。
- **备注**：P0 优先，修完必须实机复验这一条。

## P1-1 自动选中跟随是坏的（痞老板确认）

- **现象**：浏览态自动选中（三道闸）行为错误。
- **具体症状待痞老板勾选**（施工窗口需要，否则只能盲查）：
  - [ ] A 视口中心明明落在流区内、停住了，却不切换
  - [ ] B 切换了但随后又被拉回原会话（adopt 防拉回失效）
  - [ ] C 平移还没停就切了（400ms 停留闸门失效）
  - [ ] D 输入框打字时被自动切换抢走（输入锁存失效）
  - [ ] E 高亮与活跃会话不同步（高亮标错流区）
  - [ ] F 其他：______
- **逻辑面**：`paper/active-region.ts` 的三道闸控制器实现本身看起来正确（stop 取消、空白保持、同 id 不重计、adopt 防拉回）。
- **疑点集中在喂入层** `app/panels/PaperPanel.tsx:808-875`：
  - `moving` 折叠了 `panning / edgeDrag / focusRaf / inputLocked`，任何一路误报会让判定长期失效；
  - `200ms` 兜底 interval + view 订阅双轨喂入，与 `400ms` 停留计时的交互可能存在竞态；
  - `adopt` 只同步了显式动作路径，若某条显式路径漏 adopt，自动选中会在用户显式切换后立刻把它拉回去（对应症状 B）。
- **期望**：三道闸严格生效——平移/缩放/动画中不判；停住 400ms 才切；显式动作切换不被自动选中拉回。
- **备注**：**先请痞老板勾症状，再让施工窗口动手**。

## P1-2 目次带聚焦落点不符合直觉（痞老板确认）

- **现象**：点目次带锚点跳转后，目标轮次停在视口偏下、非直觉位置。
- **证据**（实机实测）：锚点一跳后，块一屏幕 y 从 79 → 485（屏高 1400，中心 720），落点在约 35% 高度处，不是视口中心。
- **根因**：`flyToPoint` → `viewFocusRegion`（`paper/canvas-math.ts:151-160`）→ `viewForAnchor`，把目标锚点对到 **「视口底部上方 margin」** 而非视口中心。目次带和书脊定位复用同一公式。
- **期望**：跳转后目标轮次落在**视口中心**（或痞老板拍板的阅读舒适区，如顶部 1/3）。改目次带时要连书脊定位一起改，保持一致。
- **落点**：`paper/canvas-math.ts`（`viewFocusRegion` / `viewForAnchor`）+ `app/panels/PaperPanel.tsx:510`（`flyToPoint`）。

## P2-1 模型选择器 UX 一塌糊涂（痞老板确认）

- **现象**：创作坞里的模型选择是一个「输入框 + 搜索下拉」：
  - 收起态只显示模型 id（如 `deepseek-v4-pro`），没有下拉箭头，看不出是个选择器；
  - 空查询默认只列当前 vendor 的模型，跨 vendor 选择要跳设置页（创作坞内选不了其他家）；
  - 下拉项 = id + 一排 meta tag（推理/上下文/价格）混排，非全屏下视觉拥挤；
  - 选中反馈弱，收起态没有「当前供应商 / 模型」的层级信息。
- **证据**：`app/panels/ModelSelector.tsx` 全文。
- **期望（最佳实践）**：
  - 收起态显示人类可读模型名 + 供应商层级，带下拉箭头暗示可展开；
  - 点击/聚焦展开可搜索下拉，键盘上下 + 回车选择；
  - 收起态附带必要元信息（推理 / 上下文 / 价格）但克制，不挤爆设置行；
  - 跨 vendor 选择至少在创作坞可完成，或明确提示去设置页。
- **落点**：`app/panels/ModelSelector.tsx` + 相关 CSS。

## P2-2 思考档位收起态零反馈 + 展开态弱（痞老板确认）

- **现象**：
  - 按钮永远显示「思考」，收起后完全看不出当前档位（实测 aria-label 恒为「思考」）；
  - 展开面板是四个小按钮「关闭 / 低 / 高 / 极限」+ 括号英文（low/high/max），中英混排；
  - 选中态只是微弱 class 高亮；「当前：高 (high)」只出现在展开面板里，收起即消失。
- **证据**：`app/panels/ComposerDock.tsx`（`pp-thinking-toggle` / `pp-composer-expanded`）。
- **期望（最佳实践）**：
  - 收起态直接显示当前档位（如「思考 · 高」或档位徽标），状态可见；
  - 展开用分段控件（segmented control）常驻一行，选中态强烈可辨；
  - 档位词统一（去掉中英混排）。
- **落点**：`app/panels/ComposerDock.tsx`。

## P2-3 权限模式循环按钮 + 突然弹确认条（痞老板确认）

- **现象**：权限是循环点击切换（常询 → 半放 → 全放 → 常询），点到「全放」突然弹出「落印 / 收回」确认条；用户看不出有几档、当前在哪、下一个是什么。
- **证据**：`ComposerDock.tsx` 的 `cycleMode` + `pp-yolo-confirm`。
- **期望（最佳实践）**：分段控件或下拉显示三档；全放二次确认用明确对话框（确定 / 取消）。「落印 / 收回」措辞若保留，需痞老板明确认可这种调性。
- **落点**：`app/panels/ComposerDock.tsx` + `state/mode-store.ts`。

## P3-1 非全屏 UI 打架（痞老板确认 + 实机复现）

- **现象**：
  - 窗口非全屏时，底部创作坞设置行（目标 / token / 模型 / 权限 / 思考）全挤一行，元素重叠、溢出；
  - 目次带底部 gap 硬编码 96px（`TocStrip.tsx` 的 `TOC_BOTTOM_GAP`），但创作坞实际高度是动态的（展开思考面板 / yolo 确认条 / 附件列表都会变高）→ 目次带与创作坞重叠风险；
  - 侧边栏弹出面板会盖住画布。
- **证据**：实机窗口 1016×708 时复现。
- **期望**：
  - 设定最小窗口尺寸，低于则禁用缩放或压缩布局；
  - 设置行允许收缩 / 换行，不溢出；
  - 目次带 bottom gap 与创作坞实际高度联动（或创作坞高度稳定化，展开内容不改变坞总高）。
- **落点**：`app/panels/TocStrip.tsx`（`TOC_TOP` / `TOC_BOTTOM_GAP` 硬编码）、`app/panels/ComposerDock.tsx`、`PaperPanel.css`。
