## 1. 决定（自裁 + 用户拍板）

| 项 | 决定 | 理由 |
|---|---|---|
| 框体 | **880 × 640 固定册页**（92vw / 82vh 兜底），头 56 / 搜索 46 / 脚 38 | 与 settings 900×640、palette 640 同族；「地方」不随条目跳 |
| 法度 | `--veil` 38% + `--elev-raise` + `border-top: --rule-head` + `veil-in`/`pop-down var(--m-ink)` | §11 模态档，与命令面板/帮助页同一套模态语言 |
| 层级 | 新 token `--z-shelf-modal: 485`；旧 `--z-shelf`（其实是牒卡）改名 `--z-prompt` | 门必须在插件窗 460 / 提示 480 之上，牒卡 500 / 命令面板 510 之下；旧名是陷阱 |
| 页签 | **器物 / 卡片**（原 软件型 / 卡片型） | 用户 2026-11-24 拍板；「软件型」页里还住着面板，词已不准确 |
| 器物页 | 名册三段：**在窗 / 软件 / 面板**；朱砂方点表状态；动作用常显（开 / 关 / 聚焦） | 门要能开、能关、能切窗——旧版只会开 |
| 卡片页 | **目录 + 阅览**：左目录按今天/本周/更早分桶，右栏选中即读；html 真跑、table 真排、file 给路径、其余文本类读 payload 字 | 卡片的价值是内容；不能「点开才知道是什么」 |
| 搜索 | 两页共用一条查询；空查询 = 全列；页签显示命中数；另一页有命中时给切页出口 | placeholder 承诺了三样，就不再只搜当前页 |
| 键盘 | `mountDialogFocus` + `↑↓`（带 `scrollIntoView`）+ 焦点在搜索框时 `↵` = 主动作 + `/` 聚焦 + Esc 逐层（改名 → 清查询 → 关） | 抄 CommandPalette / HelpSheet 的原语，不发明 |
| 删除 | 两击（第一击换文案「再按一次删除」，3s 未确认自动复位） | 与侧栏「整理模式」同族；卡片库删除本就是挪 `.trash`，不做第二套确认弹窗 |
| 类名 | 全部换 `shf-` 前缀 | 旧 `pp-shelf-*` 规则已编译进壳 bundle，产物热更**删不掉**（dev-workflow 三条边界）；换前缀 = 与旧规则分家 |

### 1.1 顺带拆出的共享件

产物域只别名 `react`、不别名 `react-dom`——直接 import `app/overlay.tsx` 会把 react-dom 内联进产物。
故把 `useDialogEscape` / `useOutsideClose` **原样**拆到 `app/overlay-hooks.ts`（overlay.tsx 继续 re-export，
旧调用点零改动），架阁与壳层共用同一份实现。名册 `shared` 加 `app/overlay-hooks.ts` + `app/dialog-focus.ts`。

## 3. 验收（用户视角）

1. **像一本册**：打开是固定 880×640，头/搜索/脚三段，遮罩变暗、入场有墨落纸的一拍。
2. **门在窗上**：开着文卷点架阁，架阁完整浮在文卷之上。
3. **器物能关能切**：在窗段点「关」窗就关、架阁不关；点行 = 聚焦/开窗并退出架阁。
4. **卡片看得见**：点一张卡，右栏立刻是它的内容（html 能勾、table 能读），元数据写清 kind/入阁/字节/来源卷。
5. **坏卡不沉默**：卡片库有一张坏卡时，架上写「N 张卡片读不出」，展开能看 cardId 与原因。
6. **键盘走得完**：打开即聚焦搜索框，↑↓ 换行/换卡，↵ 打开/摊，Esc 先清查询再关，关后焦点回到打开者。

## 4. 不做（本批边界）

- 卡片拖到纸上（模态形态下没有落点；要做先改产品形态为常驻抽屉）。
- 卡片缩略图网格（11 种 kind 里 html/chart/chem 没有真缩略，摆了就是假）。
- 卡片内容编辑（拓印语义：宿主只允许改名）。
- 卡片库排序以外的排序/重排（目录分桶已够；按类型分组留待真需求）。
- 面板的装/卸/禁用（那是设置页的事，门只管开）。

## 5. 风险与代价（诚实栏）

| 风险 | 处置 |
|---|---|
| 旧壳 bundle 里留着 `pp-shelf-*` 规则 | 类名换前缀，旧规则不匹配任何元素；不需要重建 exe 也能生效 |
| 旧 exe 没有 `--z-shelf-modal` | CSS 写 `var(--z-shelf-modal, 485)`，产物热更即正确；新 exe 取 token |
| 来源卷只对「有 sessionId」的卡显示 | 旧卡 source 缺字段就不显示（不编造）；案卷号是入阁时记的，删卷后仍是历史事实 |
| `card_read` 在快速 ↑↓ 时会多读 | 选中即读是本设计的代价；磁盘本地读、单张卡，实测可接受 |
| 覆盖旧测试 | 旧 `shelf-panels` / `shelf-card-actions` 的行为由新三份测试覆盖，整份删除（不做「改造放回」） |
