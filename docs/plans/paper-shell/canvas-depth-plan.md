## 0. 一句话

**画布上的每件东西先回答「它离桌面多高」**：影由高度给，z 序由高度带给，拿起/放开由高度变化给。
z-index 只是这条链的最后一个数字，不是模型本身。

## 1. 病灶（施工前，2026-11-22 白天）

现状的层次由三样互不相干的东西决定：

| 面 | 现状 | 病 |
|---|---|---|
| **z 序** | 流区 `.pp-region` **全部 z 1**（paper-base.css:366）；钉块/纸条 `.pp-block` z 2（paper-block.css:21）；待题纸 z 2（draft-sheet.css:28）；目次带 `.pp-toc` 5；坞槽 `.pp-composer-slot` 6；顶浮件 30；小地图 60；全局面板 280+ | 同档（所有纸 z 1、钉块与待题纸 z 2）**由 DOM 顺序定上下**；不同档是**写死的**（钉块永远在所有纸上面，哪怕一张纸被拖到它身上）。没有「拿起」这件事。 |
| **影** | 纸：`--shadow-sheet`（2/3 + 4/6，硬偏移）；活跃纸：`--shadow-sheet-active`（3/4 + 8/11）；拖拽带：`--shadow-sheet-lift`；顶浮件：`--elev-raise`；**目次带只有 inset 纸缘（无落影）、小地图无影、坞连影都没有**（`.pp-composer` 背景 transparent，只剩一条坞顶硬线） | 影是**按组件手调的**，不是按高度算的：一张纸和一条坞用的是两条不相干的规则；同档影值不单调（浮件的 letterpress 影比坞大，但坞在 z 上更高）。 |
| **灯** | **没有灯**：光影引擎 2026-11-22 落地后当天判死、整套撤除（`15a3d180`：屏幕模拟「纸受光」判死） | 画布上不存在任何统一光场，所以家具与纸之间连「同一个房间」这层关系都没有——影全是手调的运气。 |

**三条可复现的读法**（台子 A 栏）：

1. **家具像贴纸**：坞（z 6）、目次带（z 5）、小地图（z 60）都在纸上面，却都没有**落在纸上的投影**——它们与纸之间没有"距离"这个视觉量。
2. **影与遮挡打架**：活跃纸的影深一档（`--shadow-sheet-active`，注释原文「手里正拿着的纸」），但它的 z 仍是 1，仍可能被 DOM 顺序排在前面的纸盖住。影说"起来了"，遮挡说"还在下面"。
3. **谁压谁由源码顺序定**：两张纸同 z，钉块永远 z 2 在所有纸上——用户无法通过「拿起来」改变上下，只能改源码顺序（不可能）。

**根因一句**：全产品只有「海拔表」（§11 四档：地面/面板架/纸内件/纸片件/浮层/模态），
而**画布内部没有高度**——四档描述的是"面板 vs 纸"这种粗粒度，画布上同为"纸片件"的六七种东西（纸、钉块、
纸条、待题纸、目次带、坞、浮件、小地图）共用一两个影 token 与散写的 z。

## 2. 目标 / 非目标

**目标**

- 每件画布物有一个**高度**（显示 px），高度是模型，影与 z 是它的两个投影。
- **一个方向**：所有投影同向同源（左上光 0.62/0.95）。**不模拟受光**——没有灯层、没有场景；换方向 = 改一组常量，不换渲染器。
- **拿起 = 升高**：点/拖一件东西，它升到所在高度带的顶部、影加深；放开落定。上下关系永远可读、可改。
- **同带内次序可持久**（至少会话内）：最后拿起的那件在上面，不靠 DOM 顺序。

**非目标（本线不做）**

- 不做 3D/视差/倾斜；画布仍是正投影俯视。
- **不做屏幕模拟受光**（灯光层 / 窗格投影 / 加色辉光）——2026-11-22 判死（`15a3d180`），不要再提议。
- 不改流内排印件（`.pp-block` 的 flow 态仍是"印在纸上的墨"，无影）——§11 判过的死案（万物皆浮）不复活。
- 不动全局面板/模态的 280+/400+/500+ 层（那是另一张表，已经对）。
- **坞不接海拔、不接影**（用户：坞不要动）；z 按 Q2-B 只挪数字到 3200（形态仍是墨，§7）。
- 不做「把纸拖成一摞」的堆叠持久化（P4 再议）；纸仍可以自由重叠，只是上下可读。
- 不重做纸的四层物理包边（受光缘/背光缘/裱边带/接触落影）——它回答"材料"，本线回答"高度"。

## 3. 模型（一张表 + 三条规则）

### 3.1 高度带（目标态；已落地的是 0/1 最小步，见 §5）

| 带 | 东西 | 高度 px（静置 / 拿起） | z 带 | 影 |
|---|---|---|---|---|
| 桌 | `.pp-desk` | 0 | 0 | — |
| 纸 | 流区纸、待题纸 | 3 / 10（活跃）、14（拖起） | 100–999 | 接触影 + 方向影 |
| 纸片件 | 钉块、纸条、签、卡 | 5 / 9 | 1000–1999 | 同上，更短 |
| 环境 | 云影 `.pp-root::after`（窗光/辉光已撤） | —（盖在纸上，不参与拿起） | 3000–3049 | 环境影 |
| 纸面覆盖层 | 引线 / 朱线选区 / lift 遮罩 | —（画在纸上，不参与拿起） | 3050–3099 | 无（线/遮罩） |
| 架件 | 目次带、顶浮件、小地图 | 12 | 3100–3199 | 方向影（落纸上） |
| 坞 | 创作坞 | **不接**（拍板：坞不要动） | 3200（Q2-B：只挪数字） | 无 |
| 画布内面板 | 设置/命令面板等（画布内浮层） | 32 | 3300–3399 | 沿用 `--elev-menu` + veil |
| 瞬时件 | 拖拽幽灵 / 下拉 / 斜杠面板 | — | 4000–4099 | 现制，不参与上下判读 |
| （全局） | 纸壳 280 / 面板 400/401 / 牒卡 500 / 命令面板 510 / 退出 530 | — | tokens.css 现有 | 不动 |

> 带号留了三位数余量（纸带可容 900 张卷，100 卷场景不溢出）；**同带内 z = 带底 + 拿起次序**，不靠 DOM。
> 环境带必须在纸片件之上、架件之下；纸面覆盖层在纸/纸片件之上、架件之下（引线本来就是这个口径；
> 朱线现制 z 62 反而压过坞与目次带，归位后一并在家具之下）。
> **带序真源 = `paper/elevation.ts` 的声明顺序**，测试按它断言递增，不另抄。

### 3.2 影 = 高度 × 光（固定方向，不模拟受光）

```
dx    = h × 0.62 + 1
dy    = h × 0.95 + 2
blur  = h × 1.6  + 3
alpha = 0.05 + 0.009h        （封顶 0.22，再乘 --light-alpha）
接触线 = 0 1px 0 rgba(38,34,28,.16)
```

- **一个方向**：dx/dy 是**设计常量**（`paper-elev.css` 的 `--light-dx/dy/soft/alpha` 缺省值：左上光 0.62/0.95/1/1）。
  不模拟受光，所以没有"场景"；将来若真要换方向，改这四个数，规则不动。
- **两层**：近影（贴地、短、硬）+ 方向影（远、软）——一层 box-shadow 做不出"接触处最暗"。
- **落点**：影由 box-shadow 天然落在下面那一层（纸压纸、坞压纸、纸条压纸）——不需要 canvas 或 WebGL。

### 3.3 z = 带底 + 拿起次序

- 带间靠高度：高的带永远在上（坞 > 架件 > 覆盖层 > 纸片件 > 纸）。
- 带内靠**拿起次序**：一个 `Map<band, id[]>`，点/拖 = 移到队尾 → `z = base + index`。
- **P3b 已落地（2026-11-22，Q2-B）**：纸带 100–999 与带内次序由 `use-region-stack.ts` 算——
  点/拖/边角 = `raise` 到队尾，z = `zOf('sheet', index)`；坞的 z 从 6 挪到 3200（只挪数字，形态仍是墨）。
- 待题纸住**纸带**（它就是一张纸，排在纸带顶 999，见 DraftSheet）；钉块/纸条住纸片件带（1000 / 1001）。
- **流内排印件是世界层兄弟**（不在 `.pp-region` 里）：z 取 **997**——高于纸带现实档、低于墨迹层 998 / 待题纸 999 / 纸片件 1000。
  2026-11-22 实机回归：全带 z 后流块仍写 z 2，所有摊开的卷整片沉到纸下（“无字天书”）；契约测试已钉。
  **Q1-A**：公共钉块永远在纸上面（1000 > 999）——纸不能盖住钉块，这是"钉到拔为止"的语义选择。
- 拿起次序**只活在会话内**、不落盘：重开画布按摊开序恢复（次序不是布局，别偷偷持久化）。

## 4. 单一真源与接线

| 真源 | 内容 | 消费面 |
|---|---|---|
| `src-ui/src/paper/elevation.ts` | 带表（名/高度/拿起高度/z 底 + 层序 `BAND_ORDER`）、`zOf`、`heightOf` | 组件写 `--h`（或 z）内联；CSS 只读变量 |
| `paper-shell/paper-elev.css` | **一条**影配方（读 `--h` 与 `--light-*`）+ 灯的固定缺省值 + P3a 的 0/1 | 纸（暂未接影）、目次带、小地图 |
| `builtin-roster.json` 的 `shared` | `paper/elevation.ts` 登记进 compose-dock 与 paper-minimap（**无状态**共享件，构建期内联） | 两个插件的 `ELEVATION.furniture.height` |
| `tokens.css` | **高度表不进 tokens**（画布语义；且 tokens 在壳 bundle，改它必须重编 exe） | — |

**为什么数值放 TS 而不是 CSS**：高度要参与 z 排序与拿起逻辑，CSS 只负责画；若高度也写一份在 CSS，
两份必然漂移（「单一权威源」铁律）。CSS 的 `--h` 由 TS 内联写，禁止在样式表里给带高度件写死 `--h`
（P3a 的 0/1 是例外中的例外：它只动 z、不写 --h，且全文件只有这两条 z，测试钉死）。

## 6. 代价与风险

1. **剂量**：§11 判过「万物皆浮」（2026-09-05 钉块/纸条加影被判死）。本线必须守住：**只有"离开纸面"的东西有方向影**，
   纸内排印件永远无影；纸片件的影要短（5px 级），不能与架件（12px 级）同脸。台子 B 栏是偏重的演示值，落地按真机再调。
2. **坞是明账**：坞不接海拔（用户拍板），所以它在物理层次里**没有高度**——这不是漏做，是形态选择。
   任何"顺手给坞加个影"的改动都算越界，测试钉住「影配方不许接坞」。
3. **z 重排的连带面（已核对，B3）**：引线 3050 / 朱线 3051 / lift 遮罩 3052（纸之上、架件 3100 之下）；
   纸条幽灵 / 拖拽幽灵 / 下拉 / 浮钮住瞬时件 4000；墨迹层 998（纸之上、纸片件之下）；云影 3000。
   行为变更：朱线现在在家具之下；坞（3200）现在在目次带/顶浮件/小地图之上。
4. **命中与遮挡**：Q1-A 后钉块永远在纸上面（1000），纸不会盖住钉块；纸叠纸时点击天然归最上面那张
   （z 高的先命中），无需"穿透"判据。
5. **性能**：大纸（1440×长卷）的 box-shadow 每帧不变，只有拿起/拖拽换值；不要在 rAF 里改 blur。
   纸的影过渡只允许 `box-shadow` 一项（现有纪律），不要拖 `transform`（纸律）。
6. **产物热更**：影配方落在**产物 CSS**（`paper-elev.css`，随 paper-shell 产物走），不放 `tokens.css`（壳 bundle）。
   `--light-*` 也由产物给缺省值，不依赖任何壳层新 token。
7. **测试面**：`paper-visual-decisions` 的「纸/拿纸/架件」影判据已按显式规格变更改写（`933004e4`）；
   `paper-elevation` 新增全带 z 对拍、拿起次序纯函数与高度来源断言。
8. **别再提议模拟受光**：`15a3d180` 已判死（屏幕模拟「纸受光」）；台子的窗光只是判读用的示意，不是路线图。

## 7.1 实机回归与修复（2026-11-22 夜）

- **流块沉到纸下**：流块是**世界层兄弟**（不在 `.pp-region` 里），旧 z 2 是按「纸 1 / 块 2」写的；全带 z 把纸升到 100–999 后，所有摊开的卷整片无字。修：`paper-block.css` 流块 **z 997**（高于纸带现实档、低于墨迹层 998 / 待题纸 999 / 纸片件 1000），契约测试钉死。
- **纸的四层包边失效**：`.pp-region` 的 box-shadow 末层写了 `var(--elev-shadow)`，但纸区没挂 `pp-elev` ⇒ 变量未定义、整条 box-shadow 失效。修：纸区补 `pp-elev`（`PaperPanel`），契约测试钉「纸必须挂 pp-elev」。
- 两条都是**实机截图**发现，源码级测试原先只断言字符串、未断言计算值；契约测试补了归属位。

## 8. 停止条件（这条线做完的样子）

1. 画布上任取两件重叠物，**一秒内**读得出谁在上；点/拖能改变上下。
2. 影的方向全画布一致（左上光）；纸/纸片件/架件各按高度出影；**流内排印件仍然无影**。
3. 坞仍然没有影（拍板）；全局面板/模态的 z 与影一字未动。
4. 门禁：`vitest` + `build` + `biome ci` + `doc-check` 全绿；改写的视觉判据是显式规格变更、有记录。
