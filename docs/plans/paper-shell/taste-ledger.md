## 来源合并（V2 时完成正式合并，此处先记已实证的事实）

三处已付费的品味资产，DNA 连续（2026-08-20 实证）：

| 事实 | 观测台（tokens.css） | 白纸原型（paper-prototype*.html） | 墨黄铜（ink-brass-*） |
|---|---|---|---|
| 黄铜 accent | `--obs-brass-hi: #e8c887` / `--obs-brass: #c9a25c` | `--brass-hi: #c9a25c`（**与 obs-brass 完全同值**） | chronoBrass 渐变同族 |
| 动效曲线 | snap `0.12s` / glide `0.3s`，cubic-bezier(0.23,1,0.32,1) | snap `0.14s` / glide `0.32s`，**同 bezier** | 同族 |
| 衬线字体 | Fraunces Variable + Noto Serif SC | Fraunces + Noto Serif SC（同款） | 同族 |
| 语义色 | pass/warn/fail 三值 | pass/fail 同族 | — |

**合并结论（2026-08-20 R1 D-R1-5 升格为已定）**：白纸/深色 = 同一前端的两主题（昼夜两态）。黄铜 accent = 跨主题恒定的仪器 DNA；动效曲线 = 品牌级运动语言；Fraunces = 标题衬线定字体。墨黄铜（ink-brass）= 材质词汇表（跨主题取用的质感元素），非第三竞争方向。V2 契约须交付主题机制（token 双套 / 运行时切换 / 降级规则）。

- 2026-08-21 · 纸材质 · V1 第二轮 C1|C2|C3（plain|cream|parchment） · 弃 C1 冷白（"没质感"原话）；C2/C3 未获拍板 · 调色方向（暖、羊皮纸系）比冷白好，但仅调色+CSS 噪点不够"纸"
- 2026-08-21 · 纸材质·贴图密度 · V1 第二轮 D1|D2（程序化生成贴图±光纪律） · **弃 D 组**（"效果不好，质感看起来很别扭"原话） · **素材瓶颈假说被证伪**：贴图密度不是"没质感"的主因——生成贴图叠加后反而更别扭。买美术素材的钱省了；质感问题另寻根源（候选：纸感≠纹理叠加，或需真照片素材，或问题根本不在材质而在排印/构图——见待办）
  - **范围收窄（2026-08-22 R3-M 翻案注记，非翻案）**：上条证伪的实为「程序噪声平叠」——D 组贴图是算法噪声，既无真纤维结构也无光响应。后续轮次相继测了「真照片平叠」（R3-P）与「PBR 光照材质」（R3-M），原结论保留但范围收窄为「程序化贴图密度不是瓶颈」；「素材要不要买」的判定移至 R3-M 人判（判定分支见评审壳）
- 2026-08-21 · 工作面 vs 静物 · 诊断推论 · 记：ink-brass 静物是"烛光下的舞台构图"，不能当工作面目标追 · 工作面要长时间盯、内容铺满视口，与静物画的戏剧性光影天然冲突；拿静物当基准会导致永远"差点意思"（此为 C/D 两轮的共同教训）
- 2026-08-21 · 块粒度 · 走查弹涌现（用户：「长文字回复整块拖出没必要，只想截取一段」） · 选混合方案、重心选区拖出（块级默认 + 选中一段拖离流 = 抽纸条，拷贝语义）；弃段落级预拆 · 粒度交给用户按需取，流视觉密度不涨、块 id 续命机制不伤；纸条隐喻与 D-R2-3「塞纸条」同构。活引用仅块级保留，选区块是纸条本体（用户拍板：直觉与 agent 一致，并排原型取消）
- 2026-08-22 · paper 态路线 · V2 开工前岔路（下方待办二选一）· 选 V1 第三轮再攻质感；弃「从简直进契约」、弃「dark 全量 + paper 挂实验态」 · 用户拍板：白纸愿景不搁置——质感问题换思路（非贴图密度路线）再做一轮人判，之后才录 V2 契约
- 2026-08-22 · P 片素材 · V1-R3 备材（cc0 ambientCG 五张扫描纸数据侧写）· 选 Paper001（近白细颗粒，multiply 0.5）/ Paper002（灰暖重颗粒，multiply 0.45 + brightness 1.12 提亮）；弃 Paper003（云斑无细纹）/ Paper004（牛皮纸色偏离 cream 家族）/ Paper005（平滑无纹理）· 细/重两档铺强度曲线；选纸依据是均值/暖度/纹理能量统计（模型无图片输入，数据侧写代行）
- 2026-08-22 · 组合探针 · V1-R3 人判中途用户点单「排印加重颗粒出一版」· 出 T+P2 组合片（`material=r3tp2`：T 排印层级 + 纸中纸实心对比 + P2 重颗粒扫描贴图），四断言自检过（folio 结构来自 T、颗粒来自 P2、两半同时生效）· 未拍板——观察组合是「排印给骨材质给肉」还是「颗粒淹没字清晰度」；若组合赢单变量，V2 契约按排印刻度+材质管线双节立
- 2026-08-22 · 光照材质刺 · V1-R3-M（用户反馈「总觉得不对劲」+自认两病灶：表面不像/场景太干净）· 出 M1/M2 两片（`material=r3m1/r3m2`：cc0 PBR 组 Color×NormalGL×Roughness 左上光源逐像素烘焙，整纸单铺 2400px 零重复）· 未拍板待人判。**过程中的三个技术实锤**：① 此前所有「真照片材质」（P 组）只用了 Color 平叠——Normal/Roughness 从未开箱，「光响应」整轮空白，第二轮证伪结论据此收窄；② 烘焙接缝检验证实 cc0 两套扫描都非无缝贴图（color 缘差 2.5-4.7，Paper001 normal 达 10.9）——P 组 640px 平铺一直带接缝线，整纸单铺是唯一无接缝路径；③ M2 纵横纹理能量各向异性（1.67 vs 0.99，造纸机纤维方向）是平叠照片给不了的真纸特征。判定分支：M 赢→材质管线按 PBR 烘焙立项、美术资源按 Normal+Roughness+Color 三件套规格采购；M 输→表面非瓶颈，美术资源只在需要「艺术不均匀」（deckle 毛边/艺术级扫描）时按张买
- 2026-08-22 · **R3 人判：全弃** · 全变体评审（基座/T/P1/M1/M2/P2/T+P2/L）· **全弃**（「怎么都不行，很劣质，很粗糙」「你要问我好不好，我觉得都不怎么好」原话；用户进入视觉疲劳态：「做来做去搞的我不知道怎么弄了」）· 三假说无一胜出——走评审壳预设分支「全错→回账本重新立案」；**止损条款首次实际触发：禁生成第十一张变体**，下一动作只许诊断性（参照物/判断条件），不许生成性
- 2026-08-22 · 质感病理推论 · R2-D / R3-P / R3-M 三轮负结果合并分析 · 记：三批材质尝试的死亡语言一致（「别扭」「劣质」「粗糙」——全是缺陷词汇，无一是材质词汇）· 假说：屏幕是发光体，细粒度非均匀在其上被知觉读为噪点/脏污/压缩伪影而非纸材质（纸的质感前提是反射光，屏幕不满足此前提；唯一立得住的 dark 恰是近零细纹理）；CSS 渐变+扫描贴图的半吊子模拟落在恐怖谷——不够抽象不够真；且三轮都在原型工艺地板上（620px iframe、假内容、玩具块）判断天花板选择 · 两解指向同一动作：先补参照物（什么样的纸感算好），再谈动手
- 2026-08-22 · 立案重诊路线 · 止损后岔路（参照物板 / 抽象化转向 / paper 搁置）· 选**参照物板 + 全屏重判**；弃直接转向、弃搁置 · 用户拍板：先把「不对劲」翻译成差分信号再定方向——产出 `prototype/reference-board.html`（七张市面纸感产品实拍 + 我们三张同尺寸对照），人判任务=只指出哪几张感觉对
