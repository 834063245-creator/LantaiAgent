## 1. 目标交互语义（终态）

### 1.1 统一心智模型

**「纸面上的东西拖出去就是你的，你的东西拖回来就还给纸面」**——块（flow→带外）与选区（带内→带外）共用同一领域边界（流带），方向语义对偶成立。前提是**带在拖拽中可见**、**落点有实时预览**。

### 1.2 手势族终态表

| 手势 | 现状 | 终态 |
|---|---|---|
| 块拖出钉住 | 文类签 mousedown → 6px 即 commitPinned（即时建钉）→ 松手判带（带内=拔钉回流） | 文类签 mousedown → 6px 起纯预览（幽灵态）→ 全程跟手 → **松手定夺**：带外=建钉、带内=取消（不动原状态） |
| 钉住块拖动 | 同上链路（既有钉移动） | 同上（松手才写 canvas-store） |
| 按住选区拖出（路径 A） | mousedown 命中选区矩形 → 清选区+揭起遮罩 → 拖动幽灵预览 → 松手带外成条/带内恢复选区 | **保留**（手势语言核心）；补：松手在带内/画布外 = 恢复选区（现状保留） |
| 拖选跨带成条（路径 B） | 拖选文字越带界松手 = 成条 | **杀死**：拖选只做选择，永不解释为抽条手势 |
| 选中浮钮（路径 C） | selectionchange → 块内选区出现「抽纸条」浮钮 → 点击成条（stash 落位） | **保留**不变 |
| 洞（已移出）点击 | 点击 = 收回 | 保留不变 |
| 纸条拖动/调宽 | 阈值手势 + 右缘 resize | 保留（resize 不动）；拖动改松手定夺 |
| 纸条删除 | ✕ 即删 | 两击确认（首击变「确认？」态，再击执行；3s 超时回退） |

### 1.3 拖拽中领域显形（带显形）

- 触发：任一拖拽族进入 moved 态（块拖出/钉移动/选区揭起）即激活，结束后撤。
- 形态：来源流区（region）边缘信号——纸面亮一档（`background-color` 提亮或边缘发朱砂细线，施工时 A/B 定档）；**不做**全屏遮罩或动画带（过度反馈）。流带宽度概念保持 ANCHOR.bandHalfWidth 判据不变，只是判据可见化。
- 落点预览（拖块路径）：拖拽中块预览按落点分带显示「钉住/回流」态——带外 = 块影保持「钉住落位」姿态；带内 = 块影叠加「回流」提示（降低不透明度 + 文案小签「松手回流」）。拖纸条幽灵（选区路径）已有 zone 反馈，保留。

### 1.4 可发现性（一次性眉批）

首次进画布（有摊开卷）显示一次性眉批「按住文类签可把任意块钉到案上」（创作坞一次性眉批同款：6s 自散 + localStorage 旗标 `lantai.pin-hint-shown`）。复用既有一次性提示组件模式，不新建组件族。

## 2. UI 换装（判例内转录）

### 2.1 钉住块（盖章剪报）

- **换装**：`outline + outline-offset 14px` 退役 → 物理材料：纸色底（现状 paper）+ **物理包边轻量档**（流区四层配方的缩放版：受光缘/背光缘/裱边带窄档/接触落影轻档；具体四参施工时对齐 `--sheet-*` token 派生，不散写新 token，必要时 `--pin-*` 旋钮挂 tokens.css「纸内件」块）+ hover 保留朱砂信号（edge 亮起）。
- **身份签补抄**：右缘竖排「钉住」签（`writing-mode: vertical-rl`，`--f-mono` 9px 拉宽字距，seal-deep，hover 显形——原型 `.pin-hint` 转录；与收回按钮的 hover 显形语言一致）。
- **收回按钮**：保留现位（顶右角）；与身份签同 hover 显形族。

### 2.2 纸条

- **虚线退役**：`border: var(--rule-dashed)` → 物理缘（同 2.1 轻量档配方的更轻档——纸条更小、更薄）。
- 「纸条」题签 + ✕ 保留（✕ 变两击确认态件）。
- 拖拽携带态与钉住块统一（见 2.4）。

### 2.3 洞（已移出占位）

- 虚线保留（语义正确：占位），弱化一档（`--rule-dashed` 降不透明度或换更弱虚线 token）；文案「已移出 · 点击恢复」字号不变。

### 2.4 拖拽携带态与落定动效（手感）

- 拿起（moved 起）：投影加深一档 + 微抬（`translateY(-2px)` 或 scale 1.005——transform-only，不碰测量镜像，pp-enter 先例）；`opacity .92` 退役（换实义姿态）。
- 落定（松手）：settle 动画——钉 = 按下（压一拍 + 投影塌缩，拟文印 `:active` 先例）；纸条 = 放下（轻落 + 投影归位）。时长用 `--snap`/`--glide` 档内取，不新立动效曲线。
- 约束：所有动效 transform/opacity/box-shadow only；**不碰 left/top/width**（虚拟化窗口化 + resize 逻辑安全线）。

### 2.5 语义红线（宪法，不许越）

- 朱砂=人（钉住身份签、抽条浮钮、hover 信号合法）；石青=机；圆角恒 0。
- 墨阶：身份签/浮钮 seal-deep 属「人语汇」红——瞬时态/hover 态不占「每屏至多一处红」常驻名额（句读点朱条款的既有解释）。
- 纸内件投影纪律：钉住块/纸条用压印族 `--elev-raise`/接触落影派生档，禁第三种影子（层次法 §11 影两族）。
- 新样式只写 `--obs-*` 纸面 token 族（tokens.css 浸墨块）；`--pp-ch-*` 排印变量不动。

## 3. 施工切分（三刀，一个工程窗）

### 刀1 · UX 手势层（行为变更）

文件面：`plugins/builtin/paper-shell/PaperPanel.tsx`（手势 effect 区 L1968-2740 一带）+ `paper/selection.ts`（判据函数）。

1. **杀路径 B**：`up` handler 末段「非 lift + ghost.zone==='strip' + start.blockEl」分支删除（`pressStartRef` 通道退役或仅留判空）；`move` handler 对应的「无 lift 拖选跨带 ghost」分支同步删（拖选永不显示抽条幽灵）。`selection.ts` 的 `classifyDropZone` 保留（A 路径仍用）。
2. **块拖出改松手定夺**：`dragRef` 链路重写——moved 起 `setDraggingId` 照旧（幽灵态渲染依赖）但**不调 commitPinned**；`dragPos` 跟手；`up` 时统一判带：带外（新钉/移动既有钉）→ commit；带内 + wasFlow → 什么都不做（块从没离开过流——纯预览取消）；带内 + 已钉（拖回自己来源带）→ 维持现状语义「拔钉回流」或改为仅点击洞收回？**决策点 D1**（见 §4）。
3. **纸条拖动改松手定夺**：`stripDragRef` 同款——moved 起本地 pos 预览，up 才 `moveStrip` 写 store。现状已接近（up 才 commit），核对即可，主要是统一代码形态。
4. **带显形**：拖拽族 moved 起，来源 region 挂 `.pp-region--drag-source` 类（或画布根挂 `pp-drag-active`）；CSS 提亮一档；结束撤类。
5. **拖块落点预览**：`dragPos` 落带内时 dragging 块样式叠「回流」态（opacity 降低 + 「松手回流」小签）；带外保持常态。依赖同一 band 判据。
6. **纸条删除两击**：`pp-strip-remove` 状态机——首击变 `.confirm`（文案「确认？」或朱砂加浓），3s 超时复位，再击 `removeStrip`。
7. **一次性眉批**：眉批组件复用创作坞 `一次性眉批` 模式；触发 = PaperPanel 挂载且摊开卷 ≥1 且旗标未设。

### 刀2 · UI 换装（视觉变更）

文件面：`PaperPanel.css` + `tokens.css`（若需 `--pin-*` 旋钮）。

1. 钉住块：删 outline 系规则，落物理包边 + 接触落影；`.pp-block.pp-pinned` 的 `box-shadow: var(--elev-raise)` 换四层配方轻量档；补 `.pp-pin-hint` 竖排签（JSX 侧 BlockView 钉住态渲染——PaperPanel.tsx 轻改）。
2. 纸条：`.pp-strip` 虚线退役换物理缘轻档；`.pp-strip-remove` 两击态样式。
3. 洞：弱化一档。
4. 带显形 CSS（配合刀1 的类名）。
5. 钉值测试同步：`tests/paper-visual-decisions.test.ts` 更新字面量断言（outline 退役断言、pin-hint 存在断言、strip 物理缘断言、带显形类断言）。

### 刀3 · 手感动效

1. 拿起态：`.pp-dragging` 家族重定义（投影加深 + 微抬）；opacity .92 退役。
2. settle：钉住落定 / 纸条落定的 `@keyframes`（transform/opacity/shadow only）；挂类时机 = up 后 commit 前后一帧。
3. 洞显形/恢复过渡、ghost 进出场微调。

## 4. 决策点（默认案已行，施工中遇到再回来确认）

- **D1 · 拖块回带语义**：已钉块拖回来源带内松手 = 现状「拔钉回流」保留（推荐，与心智模型自洽：拖回纸面=还回去），还是收紧为「仅点击洞收回」（更保守，杜绝拖动中误入带内丢钉）？**默认保留现状**，带显形 + 落点预览后误触面已大减。
- **D2 · 包边剂量**：轻量档四参（lit/shade/band/shadow 各值）施工时出 A/B 对照（用户失去设计件审批能力，agent 自查定档——参照 `prototype/edge-ab.html` 方法），实机看效果。

## 6. 验收清单（真机）

1. 按住文类签拖块出带外松手 → 钉住成立，钉上有竖排「钉住」签（hover 显形）；流内洞出现。
2. 拖动中可见流带高亮 + 落点带内时块影「回流」提示。
3. 微拖（<6px）松手 → 什么都没发生（不建钉不挖洞）。
4. 拖选一大段字跨出带界松手 → 只选中，不出现纸条（路径 B 已死）。
5. 选中文字 → 按住选区拖出带外松手 → 成条；松手在带内 → 选区恢复原样。
6. 浮钮路径正常；纸条落在流带右侧空地不压旧条。
7. 纸条 ✕ 首击变确认态、再击删除、3s 超时复位。
8. 纸条/钉住块拖动松手才定稿；落定有 settle 手感。
9. 重启后钉/纸条/洞/带显形恢复正常（canvas-pins/strips.json 读写不回归）。
10. 视觉：钉住块/纸条是纸制品观感（物理缘+落影），无悬空细框、无虚线框（洞除外）。
