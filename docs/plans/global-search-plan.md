# 全局搜索（Ctrl+K）：命令面板升级为「一框搜卷 / 命令 / 设置 / 文件」

> 状态：**✅ B1+B2 已落地（2026-11-28）**——用户拍板 B 案「给命令面板真活干」，并选「一次做完 B1+B2」。
> 触发：用户连问两句——「创作坞里的『案』是不是毫无意义了」「命令面板真的有用吗」。
> 前者见 §7（悬而未决，独立小批）；后者就是本文档的立项理由。

## 0. 结论先行

旧命令面板的内容实测 ~14 条，**九成是别处已有更快入口的东西**（侧栏钮 / Ctrl+P / Ctrl+,
/ 输入框打 `/` 就地出的斜杠面板 / 样例插件命令 / 调试命令）。⇒ 它既不是发现面（内容太少且可见），
也不是效率面（都有更快的键）。**但它指着一个真需求没人管：卷多了以后「上次那个话题是哪一卷」找不到。**

⇒ 升级为**全局搜索**：一框搜四类，选中即跳或即做。

| 组 | 命中什么 | ↵ 之后 |
|---|---|---|
| **卷** | 磁盘上所有卷的卷名 / 卷号；已摊开的标「已摊开」 | 已摊开 = 切过去；未摊开 = 摊开并定位（与侧栏/签条同一手势 = `activeSpace().expand`） |
| **命令** | 原三源原样（内置动作 + `ctx.commands` 贡献 + 会话内建/技能命令） | 原样 |
| **设置** | 八个设置页签 | 打开设置并**落到那一页** |
| **文件** | 工作区文件（与坞内「引」同一把匹配尺子） | 加进当前卷（`ChatCore.attachIntakePaths`，与「引」同一条路） |

## 1. 成本纪律（打开手感 = 零扫盘）

1. **空查询只列命令**：不读卷表、不扫文件（打开面板不许卡）。
2. **卷表**：首次**非空**查询读一次（`core.listSavedSessions(projectPath)`，与案头签条同一调用）；
   读失败 ⇒ 卷组整体不出现 + 一行可见原因（不静默吞）。
3. **文件**：查询 **≥2 字**才扫，且**每次打开最多扫一次**（结果缓存到关闭为止）；
   沿用「引」的 Rust 护栏（深 3 层 / 2000 项 / ignore）。
4. **每组上限**：卷 5 / 设置 3 / 文件 5 / 其余组 8，总计 20（面板不许滚成瀑布）。
5. **排序**：卷按 `savedAt` 倒序；文件按既有子序列打分（basename 加权）；命令保持原分组序
   （不引入「最近使用」权重——没有数据支撑）。
6. **空查询时设置页签让位**：它们是「改设置」的动作，不该占「打开就会看到」的第一屏。

## 2. 不做（明确边界）

- 不搜**卷内容**（全文/语义）——成本与口径都太大；留作 B3，不承诺。
- 不跨工作区。
- 不动斜杠面板（输入框里打 `/` 原地可用）。
- 不做收藏 / 自定义别名 / 最近使用排序。

## 4. 与旧行为的差异（用户可感知）

- 输入框占位符：`输入命令、面板或符号名…` → **`搜卷、命令、设置、文件…`**。
- 空态文案：`无匹配命令` → `无命令`（空查询）/ `无匹配`（有查询）。
- 页脚：`LANTAI COMMAND` → `LANTAI SEARCH`。
- 空查询不再列「设置 · <页签>」那 8 条（它们只在打字后出现）。
- 列表右端多一列注解（卷的「已摊开/未摊开」、文件路径）。

## 7. 「案」抽屉退役（同日第二批，✅ 已落地 2026-11-28）

同日问的另一问——「案」抽屉的五项里，**组合 / 图版 / 翰 / 造模式 都已有等价入口**，只剩「律 = 快捷键总览」
一件真东西。用户拍板「先做掉」，于是：

| 原抽屉项 | 去处 |
|---|---|
| 组合 | 卷首芯片（空白卷可拨）+ 纸上题签——抽屉那份是第三个入口 |
| 图版（一行读数「架在匣下」） | 坞下那排架本身；这行只是空话，随抽屉消失 |
| 翰 | Ctrl+K 本身；连带 `onOpenPalette` 一并删 |
| 造模式 | 落纸后题签选 creator（等价路径已存在，抽屉是绕一圈） |
| **律（快捷键总览）** | **`app/HelpSheet.tsx`**（数据 `app/help/shortcut-groups.ts`），入口 = 全局搜索 / `runAction('shortcuts')` |

删除面：`SchemeDrawer` 组件与全部 props、输入行的「案」钮（引/夹/案 → 引/夹）、
`use-composer-layers` 的 `schemeOpen` / `helpOpen`（浮层族收窄成 引/墨/役）、`onCreatorDraft`、
`dock-copy` 的 `HELP_GROUPS`（搬家）、`paper-composer.css` 的 `.pp-scheme-*` / `.pp-help-inline` 整段。

**行为变化（用户可见）**：坞的输入行少一枚「案」；快捷键总览不再要点进抽屉，Ctrl+K 搜「快捷键」即可
（或任何绑到 `shortcuts` 动作的入口）。测试面：`composer-dock-composition-chip`（整文件，行为退役）
同批删除；desk / header / settings-pair 的旧断言同批改写或删除；新增 `tests/help-sheet.test.tsx`（3 例）。
