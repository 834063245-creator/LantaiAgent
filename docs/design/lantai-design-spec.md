# 兰台前端 · 设计规格书（v1 · 落地前置）

> 本文是 `holo-paper.html` 原型锁定的设计决策，供 `src-ui` 工程落地对照。
> **「已锁定」是契约，落地时不许回退；未列出的像素细节（字号/间距/图标形状/hover 态）可在真环境再磨。**

---

## 0. 一句话定位

**兰台＝汉代皇家档案典籍库。** 产品不再是「聊天窗」，而是**一部正在被编纂的案卷**——人在纸边批注、AI 居中撰文、机器贴底注记。核心是把「等权消息流」换成「注疏层级」。

## 1. 版式范式（已锁定）

**注疏横排**。文字全程横排（代码、英文、URL 不折行），但骨架是古籍注疏的层级，不是聊天气泡：

- **正文**（答 / 策）居中，是案卷的「经文」，正文位、大一号（17px 起，行距 2.0）；
- **来文**（问）是人的批注，手迹位 + 朱砂深 16px/1.9（B4 环1 定稿），左侧 2px 红批线；
- **夹注**（思）缩进列边（约 86% 宽），石墨铅笔，小一号，虚线勾边；
- **脚注**（器）贴底小字，上方一道 44px 石青注线引出；
- **抄录**（码）栏内图版（3px 硬左线 + 上下规线 + 米黄底）；
- **卷首**：亭台图标（`#icon-lantai`）＋ 卷次 ＋ 标题 ＋ 日期 ＋ 朱砂短横（**2026-09-02 改档只挂活跃卷**——整屏至多一处红（浸墨③），红在哪卷即活卷；对原型 `.folio-head` 的主动偏离——原型先于真纸材质批与一纸多卷定案）；
- **界栏**：正文列左右各 1px 栏线（`--rule-strong`），页边注在左栏外（**2026-09-02 翻案**：08-30 把界栏落成「流区四边版框双线框」的读法判死——纸缘交还材料、改物理包边（见 §10 纸层次·流区真纸）；版框＝「印在纸上的墨」，流区这张「叶」不印框——WebGL 探针 `prototype/webgl-paper.html` 判读定案）；
- **划词**（2026-09-02 视觉迭代）：流区选区＝手写朱笔下划线（`src/paper/sel-ink.ts` 纯函数——主笔朱砂实线 1.7px＋淡墨 echo 第二笔，种子取选区文本 hash、同选区恒同线；跨块选区也画线）；原生 ::selection 洗底在流区退役（composer/菜单等 UI 面照旧）——纸不动、只落墨，被人手划过的字落朱线；
- **印章**：朱砂「蘭臺」二字竖排印，作品牌签名。

## 2. 字体系统（2026-09-10 三体换代拍板重锁）

| 角色 | 值层 | 装载 | 备注 |
|---|---|---|---|
| 正文位 `--f-song`（原宋体） | MiSans | `src/app/fonts.css` @font-face（`src/assets/fonts/MiSans-VF.ttf`，VF 单文件 100-900 全字重） | 原宋体/衬线正文 |
| 手迹位 `--f-kai`（原楷书） | MiSans | 同上 | 只用于「人的」来文——文类语义保留，手写感随三体退役 |
| 机读位 `--f-mono`（原等宽） | MiSans | 同上 | 代码/工具/编号——非等宽对齐为拍板接受的代价 |

字体栈（CSS 直抄，文类语义键保留、值层统一）：

```css
--f-song: "MiSans", "PingFang SC", "Microsoft YaHei", sans-serif;
--f-kai:  "MiSans", "PingFang SC", "Microsoft YaHei", sans-serif;
--f-mono: "MiSans", "PingFang SC", "Microsoft YaHei", sans-serif;
```

**装载**：`src/app/fonts.ts` 只 `import './fonts.css'`（本地 @font-face，打包进应用不依赖系统安装）；fontsource 四包（eb-garamond / ma-shan-zheng / ibm-plex-mono / noto-serif-sc）已卸载。

> 关键纪律：**斜体走合成伪斜**（MiSans 无 italic 字形，`font-style: italic` 由渲染器合成——拍板接受）；canvas 侧字面量栈（type-tokens `FONT_STACKS`、InkLayer `LABEL_FONT_STACK`）与 tokens.css 同步改。

### 4.1 正文（markdown）子元素版式与折叠机制（2026-08-30 补记）

正文块（`markdown`）不再是纯文本平铺——子元素按注疏版式降级渲染；结构模型 = `paper/markdown.ts` 单一解析（渲染与测量共用，块高镜像 `measure.ts` 的 `MD_*` 常量，CSS 镜像 `.pp-md-*`，改版式三处同步）：

| 子元素 | 版式 |
|---|---|
| 段落 | 17px/2.0，段间 14px（旧 10px 段距小于行距、段落黏连，专项提到 14） |
| 标题 h1–h4 | 20/18/16.5/15.5px 正文位加粗，padding 承担上下距（首元素 margin 逃逸会破坏测高，禁 margin-top） |
| 列表 | 标记列等宽小字绝对定位（ul `·` / ol `n.`），条目缩进 26、嵌套再缩进 22 |
| 引用 | 石墨左线 + 缩进 + ink-2 |
| 图码 | 石青左线 + 深纸底（独立 `diff` 块之外幸存围栏的兜底面） |
| 远端图（2026-09-09 multimodal-image B4） | 独立行 `![alt](http/https)` 固定盒 160px（`--pp-md-imgBoxH`，chem 先例同族——加载/失败态都不改版面，measure 静态镜像即精确）；协议白名单过在解析层（非 http/https 降级 alt 文本，空 alt 整行不产块——data: 巨串不灌纸面）；周框 `--rule-soft` + 深纸底；加载失败换 mono 弱墨 alt 行（盒界常在，错误不静默） |
| 表格 | 等宽 11.5px + 弱规线（`.pp-grid-table` 同族） |
| 行内 | 加粗 600 / 斜体 / 删除线石墨 / 行内码等宽小号 chip / 链接石青下划线 |

**块体白空格纪律**：`.pp-body` 恒 `white-space: pre-wrap`——measure.ts 的 canvas 测量一律按 pre-wrap 计行，渲染端折叠换行会产生「测得多、渲染少」的幻影块间距（2026-08-30 间距根因之一，已修）。

**折叠机制**（`paper/fold.ts`；规则态 + 用户覆盖态）：夹注（reasoning）恒折叠——流内只留一行预览；脚注（tool）/程文（code）按状态折叠——`running`/`error` 展开（过程与错误可见），`done`/`pending` 收起（完成即收）；折叠行 = 块顶等宽小字（单工具 `▸ 名字 判别摘要 · 输出 N 字` / `▾ 收起`），用户点击写入覆盖态（状态翻转自动收回不打架）。**判别量**（stream-rhythm 刀4a，2026-09-03）：压缩的是重复不是信息——工具组折叠行露判别字段（`▸ 工具 ×3 · read_file src/a.ts / src/b.ts / src/c.ts`；shell 露命令；截断/同值去重补 ×N 总账；无判别字段回退名字计数），折叠行恒一行（10px mono，测高镜像零变化）。折叠态计高与渲染同步镜像：脚注折叠全收、程文折叠收程序体留输出/错误（执行结果一眼可见）。

**文类签（页边注）**：来文 / 正文 / 夹注 / 脚注 / 抄录 / 拟策（贴黄），配机读码 `USER / AGENT / THINK / TOOL / CODE / PLAN`。

### 4.2 会话流节奏（2026-09-03 stream-rhythm 立法 · D1 试值待真机终审）

会话流不是等距块栈：事件按语义关系组成**工作单元**（tool / toolgroup / code / subagent 连续运行 + 挂靠夹注；error 块起「恢复单元」），单元内紧、单元间松、阶段完成换气。规则真源 = `paper/group.ts`（单元封套）+ `paper/canvas-math.ts`（间距档 ANCHOR 表），钉值 `tests/paper-stream-rhythm.test.ts`。

| 档 | 值 | 语义 |
|---|---|---|
| 单元内 intra | 32 | 行为链紧密纵向连接（同一工作单元相邻块） |
| 块距（基线） | 48 | 无节奏信息的外部调用面兜底（B1 不动） |
| 单元间 unit | 64 | 同回合内工作单元切换 |
| 转折 recovery | 96 | Error 起的恢复单元 / 墓碑前置放空——打破正常节奏 |
| 阶段 stage | 96 + 弱线 | 来文开新阶段：留白 + 细线（`--rule-soft`，落间距中线） |

叠加律：上方是来文恒尾距 8（B1 反转：asterism 让位优先于节奏档）；B1 来文间距反转与阶段档共存。

两宪法（单元封套 pass 的结构保证）：**封口纪律**——已封口单元不可变（id 锚首成员、成员只增不减），活尾（streaming 消息）才许重排；**跨消息前瞻禁止**——挂靠（夹注吸入下一工作单元）只在同消息内发生，单元不跨消息（消息边界即收口）。阶段标题不自动生成（自动起名会撒谎）——plan 标题 / commit message 等显式信号由后续批次继承。

**刀3 布局保证（2026-09-03 补记）**：封口前缀 = **刚体**——追加事件只许整体平移，封口块的节奏档/间距/相对位置逐字段不变（布局级测试钉死，滚动锚定的数学面）；流式重排平滑 = `pp-stream-live` 下 transform 过渡 200ms（旧块被轻轻推开，绝不瞬移、绝不挂 left/top/height）。**组原子性**：折叠组 = 布局栈单条目（子卡摘除——虚拟化窗口对组只能整取整舍），展开组成员在栈内连续（窗口切不出交错序）；长流（千块级）全链回放有性能烟测预算。**目次带阶段导航（刀4）**：阶段锚消费工作单元（`buildStageAnchors`，阶段 = user 单元，与阶段间距/细线同真源），hover 兜底带阶段序（`阶段 N · 首句`）。

**Error 墨色家族（刀4c 确认，现状合规零改动）**：错误状态色 = `--fail`（#a9443f 墨浓红，非纯红非朱砂——B5 红绿墨色化延伸）；错因墓碑（turn-error）= 贴黄款——朱砂淡底只作纸晕（`--seal` 7% 混纸），墨身走 `--ink-2`；工具/程文错误输出与状态签走 `--fail` 单一真源。**朱砂 = 人铁律不挪用**：错误文字永不直用 `--seal`。钉值 `tests/paper-visual-decisions.test.ts`（Error 墨色家族三断言）。

**刀5 族节奏批（2026-09-03 补记——用户真机判「整个会话流还是瀑布」的根治批）**：节奏词汇的判据从块 kind 升级为**节律族**（读/写/验证/落款——`grammar.rhythmFamilyOfBlock`；other 不表态不断节奏，远端/未知名不破语法铁律的节奏层延伸）：**族边界切单元**——已知族切换（读→写、写→验证、验证→落款）即封口旧单元开新工作单元（errorish 转折优先于族界；recovery 同族重试续收、异族切出），WorkUnit 带 family；**折叠组按族切分**——连续工具族变即断组（「读 ×3」「写 ×2」「验 ×1」各自成行，判别量各露各的），unit 64 在族间开火、32 收在族内；**单元界短规线**——work 单元首成员上方 96px 短线（比阶段全宽线弱一档，落 unitGap 64 中线 top -32；叙述不碎、转折自宣告、来文后 B1 反转区无线位）——线语法三级：全宽 = 阶段界 / 短线 = 单元界 / 无线 = 同单元收紧；**验证链毕锚**——verify 工作单元链毕出「✓ 阶段完成」小字（ink-3 mono，链末块下方，不占块高），失败转折（后继 recovery）不发、流式在跑不发——✓ 不说谎；**组头族签**——折叠行前缀族字（`▸ 读 ×3 · read_file a.ts / b.ts / c.ts`，验/落同款，混族回退「工具」）。钉值 `tests/paper-stream-rhythm.test.ts`（族切组/族切单元/other 不表态/recovery 族续/链毕四态/单元线规则）+ `tests/paper-visual-decisions.test.ts`（刀5 四断言）。

**2026-09-06 尸检补记（用户真机报「渲染隐约不对、说不出病灶」）**：线语法两条隐蔽执行修正——①**单元线实现机制**：块级 ::before 与脚注族注线（`.pp-tool/.pp-toolgroup/.pp-code::before` 石青身份标记）同槽同特异性，源序落败被静默顶掉 → 单元线在工具族首块上整体消失；改实元素 `.pp-unit-rule`（壳层条件渲染，钉值不变），线语法三级语义不变；②**栈首无线位**：阶段线/单元线的负偏移对栈首块画进卷首头带（-48 落 head 底规线上方 ~18px 每卷必现错位线）——线标记「上方有界」，栈首之上只有卷首（天然界），`rhythmAssign` 以 `i > 0` 守卫两线发放（节奏档不动）。回归钉值：paper-visual-decisions「槽位独立性」+ paper-stream-rhythm「栈首不发线」。

### 9.1 墨量册（2026-09-13 落地）——坞内 token 计量装置

**来由**：坞是「配置 + 输入」的家，用量是落笔前最该看的读数（还能喂多少上下文）。DSH 同判——上下文表放在输入条旁（ContextMeter 环），不另开页。坞底墨量线继续做余光可见的环境指示，墨量册是它的展开面：**点开看账**。

**落位**：设置行最右端一枚「墨 NN%」触发器（`.pp-ink-sel`——读数件不是控件，不进「权限+思考」运行策略对，独立居行尾；与思考 pill 同语言：纯文字 + 小墨点，>80% 墨点与文字转朱砂）；面板向上开（坞贴屏底），并入浮层互斥（思考/翰/律/引/墨五层同屏只开一个）。

**册面（全出自 `src-ui/src/agent/token-meter/`，真源 = Agent 侧每卷账本）**：
- 书眉：卷名 + 来源徽记（`回报` / `估算`）；
- **读数**：占用百分比当**全册唯一题字**（26px/700），右陪小字距标签「上下文已用」，近满（>80%）转朱砂（句读点朱——全册唯一红字）；
- 副行（mono 小字）：`~已用 / 窗口 tok` + `下一请求预计 ~N`；
- **占用条**：总长 = 窗口占比，段宽 = 构成比——三段按**墨阶递减**（系统提示 `--ink-1` / 工具 schema `--ink-2` / 对话 `--ink-3`），纸墨体系只有墨，不引第三色（石青=运行态、朱砂=人的动作，均不占）；条下一行**构成图例**（色点 + 段名 + `~值`，与条同序同色相）；
- **账目**（段题「账目」）：四桶（未缓存输入 / 缓存读 / 缓存写 / 输出）+ 收口行「合计」（字重上提 + 上弱线）+ 缓存命中率；
- **本轮**（段题「本轮」）：请求次数 + 最新一轮用量；
- 页脚一句口径说明：`~ 本地分词估算 · 账目四桶来自服务商回报`。

**排印（同日二版，用户打回一版「不好看，文字排版搞一下」）**：一版是十三行等重小字竖排 = 设置表单面孔。定稿改为**册页四层**：① 一屏只许一处读数当题字（其余全部退到 10–12px）；② **段题复刻首页节题语言**（8px 实心方墨锚点 + 10px/600/字距 0.26em 题字，浸墨⑤ 完工动作）——两段之间用段题分隔，不用裸分隔线；③ **账目 = dt/dd 两列网格 + 数值右对齐**（账本竖排对齐，眼睛读竖列不读横排；`tabular-nums`）；④ 段内行高 24px、收口行 29px——节奏靠字重与线，不靠等距堆叠。踩坑留档：滚动 flex 列（`max-height` + `overflow-y: auto`）的子项必须 `flex: 0 0 auto`——默认 `flex-shrink: 1` 会把占用条挤成 0 高（肉眼只当「线画得细」，数字自查才逮到）。

**口径纪律**（沿 DSH，禁漂移）：① 分桶**互不重叠**且输入三桶加总恒等于提供方 `prompt_tokens`（残差法归一，不信任各家 miss 字段自洽）；② **压力只算 prompt 侧**（不含输出）——「占用」问的是下一次请求的提示词有多大，不是上一次账单有多大；③ **投影占用** = 压力 + 采样后载荷的带符号增量（流式期间水位站住、跨请求才前进；压缩把载荷削小时同步回落，夹零不出负数）；④ 构成是**估算构成**不是账单（本仓用 gpt-tokenizer 计数通道，与压缩预检同一把尺子）；⑤ 缓存命中率**部分命中绝不四舍五入成 100%**（DSH `formatCacheHitPercent` 的诚实舍入照搬）；⑥ 账本随卷落盘（`.lantai/sessions/{id}.json` 的 `tokens` 字段，旧卷无此字段 = 从空开始，不迁移不编造）。

**归属铁律不变**：创作坞仍是「视图不是容器」——账本真源在 Agent（`getTokenStats/snapshotTokenLedger/restoreTokenLedger`），坞只读；卷级 `sessionTokens` 降为「总量投影 + 重算触发信号」。

**书眉卷名吃满余量（2026-09-13）**：`.pp-composer-target` 原 `flex: 0 0 132px` 定宽把卷名一律截在十来个字，而行内大半空间空着（右端只有翰/律两枚小钮）——改 `flex: 0 1 auto` + `max-width: 64%`：短名不虚占、长名吃到可读上限，换卷/改名仍不推挤右端（spacer `flex: 1` 吸收余量），超长仍 ellipsis。

## 10. 浸墨法则（2026-08-31 全局视觉立宪 · 用户拍板 B）

## 12. 案卷侧边栏（2026-09-02 UX/浸墨批）

八件定案（用户拍板：选中 B 墨洗 / 可调宽 / 保持覆盖 / 缺口全做 / 互斥两态）：

1. **互斥两态**：书脊列 = 侧边栏的**收起态**——左缘任一时刻只留一个。侧栏展开（`left:0` 独占左缘，书脊整列退场）；收起（书脊回场，`sr-slide-in` 回场动画）。canvas-nav 插件以**终态不变量**裁决（并陈 → 书脊退；纸开而两关 → 书脊回），对热替换遗留「双开」态自愈。书脊专项改造另立工程（用户预告）。

## 11. 层次法（2026-09-01 立法 · 三轴模型）

来源：全面审计批（生图 mockup 对照 + CDP 全面截图取证，`D:\tmp\ui-audit\`）。层次感的本质 = **让「上面」变得可信**。三根轴朝同一答案发力，只动其一皆塌：**海拔**（谁浮在上面→光影）、**包含**（谁属于谁→线）、**轻重**（谁重要→墨）。

**海拔轴**——梯子全产品四档，token 取值禁散写：

| 档 | 东西 | z-index（§8 立宪） | 影 | 要求 |
|---|---|---|---|---|
| 地面 | 画布/纸/首页 | — | 零投影 | 多数元素住这里 |
| 面板架 | 坞面板根/书脊架/案卷侧栏 | 280/281/282（`--z-paper-base/rack/sidebar`） | 零投影 | 面板级骨架，恒在地面上、浮起件下（2026-09-01 海拔批补立） |
| 纸内件 | 块/纸条/签 | 纸内 10-60 | 无投影 | 靠遮挡+界栏线+选中线表达 |
| 浮层 | 引/思考/斜杠/翰律/模型菜单/状态线下拉 | 45-90 | `--elev-menu` | 必须盖住内容 |
| 模态 | 设置/命令面板/媒体预览 | veil + 400/401/520 | `--elev-raise` + veil | veil 必配（媒体预览加墨幕） |

规则：① 影分两族按材质隐喻取用（2026-09-01 海拔批修法）——纸片件（模态体/主钮/浮钮/拖拽幽灵/Toast）用压印族 `--elev-raise`（letterpress `2px 3px`，左上光，方向乱则层次死），悬浮面板（下拉/菜单/命令面板）用漫射族 `--elev-menu`（离纸环境软影）；两族之外禁第三种影子 ② 浮层必须盖住内容才配海拔——什么都不盖的回地面 ③ 模态必配 veil（「下面还在但退后了」）④ 档间差必须可见（浮层与模态不可同脸），差在 veil/z/线，不靠影的大小。全局瞬时层（Toast/拖拽幽灵）住 `--z-dialog` 520 带、纹理层 `--z-grain` 之下。

**包含轴**——线是结构语言，分级使用禁倒挂：版框双线（`--rule-frame`，页缘/流区叶框）> 硬线（`--rule-hard`，浸墨③三处）> 强线（`--rule-strong`，界栏）> 弱线（`--rule-soft`，同层细分隔）> 虚线（`--rule-dashed`，草稿/占位）。小事绝不用重线。头线（`--rule-head`，2px ink-2 浮层菜单书眉顶缘——ms-dropdown/sl-log）与语义缘不入分级序列，属判例件。

**嵌套语法**（2026-09-01 包含批立）：① 线随包含级数递减——页面级容器版框/硬线，面板级强线，卡级弱线，行级发丝（`--line-soft`）；外框级数必须 ≥ 内框，外弱内强=倒挂。② 一个方向至多两层框，第三层用界栏/留白/墨洗表达，不立第三框。③ 语义缘不入线级——选中线（2px 朱砂底线/左脊）与警示缘（warn/fail/indigo/pass 左缘 2px）是状态语汇，每件至多一条。④ **泛选择器框禁令**：`XX button` 类泛框必泄漏进嵌套组件（实锤：`.pp-composer button` 强线泛框曾把模型菜单条目全框成卡中卡，特异性压过 `.ms-item` 三边 none）——按钮样式各钮自带，不立泛框。

**轻重轴**——墨阶四档（§3）+ 字重极端（§10 法则 2）+ 语义铁律（朱砂=人/石青=机/石墨=草稿）。上层全对比，下层降对比（veil 压暗、淡墨、发丝线）——印刷品的层次从来靠墨量不靠描边。

**选中语言分型**（2026-09-01 审计定案，细化 §10 法则 5）：锚点型选中（tab/分段主动作）= 墨底反白，或重墨 600 + 2px 朱砂底线；行型选中（列表行/菜单项）= `--sel-wash` 墨洗 + 朱砂左脊。全产品只许这两种，禁第三种。

**致死四动作**（审计实锤，见账本 2026-09-01）：万物皆框 / 万物皆浮 / 散写影子 / 混材质（玻璃≠纸）。

**四问清单**（新面板/组件过审用）：在哪一档？z/影/veil 从 token 取了吗？投影方向与光源一致吗？——它盖住了谁？什么都不盖的，回地面去。

## 13. 目次带 v3（2026-09-14 立法：从「滚动条」到「识别面 + 目次」）

**用途排序（用户拍板，优先级即此序）**：① 精确跳到某一轮/阶段 ② 当前滚动位置的连续控制（滚动条语义）③ 一眼扫出「哪里长、哪里有错、哪里是工具密集段」。

**病灶实测**（实机 CDP，2026-09-14；用户当卷 = 289 刻痕 / 带高 1096px）：289 枚刻痕全做成 button 命中盒（10×8）——tool 刻痕 255 枚把 18 枚阶段锚挤进**平均 3.8px 间距**，命中盒相互叠压、DOM 后渲染者胜：**点自己那枚的比例 7.3%**（268/289 被相邻刻痕盖住），用户读作「刻痕点不中」；289 个 tab 停靠点同样是键盘灾难。另一头：刻痕盒 `top = stripY − 4` 会顶进书眉（＝窗口标题栏，`-webkit-app-region: drag`）拖动带，那 4px 命中归标题栏＝拖窗口。

**四层职责分离**（甲，2026-09-14 落地 `b774f4c1`）：

| 层 | 是什么 | 鼠标语义 |
|---|---|---|
| 可点层 | **阶段锚**（朱砂横规；28px 命中盒 ≥ 热区纪律 24px；盒宽只占左缘栏 26px） | 带内**唯一可点目标**——点击 = 飞到该阶段首块；按下锚不启动 scrub |
| 装饰层 | 语义刻痕（tool/plan/error 全部 + 无阶段单元的用户块）：惰性 div + `aria-hidden` + `pointer-events:none` | **不可点**——点它 = 点带空白 = 按位置 scrub（纯扫读信号） |
| 控制层 | 滑块 + 带空白处（VSCode 语义：拖拽 scrub / 点外即跳对中心；夹紧域 = 可见视口） | 连续控制 |
| 识别层 | canvas 墨迹缩略（**乙，待定档**） | 不参与命中 |

两条硬约束：**命中盒与 hover 卡同源**（卡片所示即点击所得——① 锚盒内「阶段 N · 首句」② 贴着装饰刻痕读那枚并提墨一档 ③ 行盒原文）；**映射区永不与书眉带重叠**（映射区顶 = 书眉下缘 + 刻痕半高，带外按下一律不响应——书眉带归标题栏、坞下装饰带无语义）。

**识别层（乙）的物理下限与四个正交通道**：带内缩放比常在 0.005–0.012（长卷 10 万世界 px → 528px 带），此比例下正文 15px 字 = **0.08–0.18px 高**——真字形必然不可辨（v2 退回 bar 的原始理由，见页面原型对照栏）。能携带信息的只有四个**正交**通道，各自的值由原型逐案实测（`prototype/toc-thumb-ab.html`，不入库）：

1. **形状**（行宽剪影）：空行率 0.39→0、墨覆盖 0.44→0.77，与基线 α 差 0.35；
2. **族色**（人=朱砂 / 正文最重 / 程文与工具=石青 / 图表最轻 / 错=`--fail`）：与形状案同形，rgb 差 0.086；
3. **族纹**（表=横纹 / 码=细横 / 图=点阵 / 工具=斜纹）：墨覆盖 0.77→0.68，α 差 0.21–0.32——**不靠色也分得出族**（灰度/打印成立）；
4. **墨量**（形 + 深浅双通道）：α 差 0.05–0.12——答「哪里长／哪里密」。

**淘汰案（同一把尺子判死，勿复活）**：*缩进剪影*——缩进 19 世界 px 在带内 0.2–0.6px，与形状案像素差 0.001（等于没画）；*阶段分带*——阶段界已由可点层承担，缩略里再画一遍与形状案差 0.003（纯重复）。**通则：凡小于带内 1px 的世界结构（缩进、块间留白、单行折行）一律不可辨**——识别层的设计尺度以此为准。

**现状**：甲已落地（`b774f4c1`，钉值 `tests/stage4-toc-stage-anchor-layer.test.tsx` 五例 + `stage4-toc-titlebar-band.test.tsx` 两例）；乙待用户在原型 A/B 台上挑通道组合（四通道可叠加，预计终态 = 形状 + 墨量 + 族色/族纹择一）。
